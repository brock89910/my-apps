renderAll()                  → calls every render function at once

── NAVIGATION ──

showToast(msg)               → bottom toast notification

── DASHBOARD ──
renderDash()                 → dashboard stats, bill reminders, print alerts

── BILLS ──
addBill()                    → add new bill form submit
renderBills()                → renders bills table with filters

setDoneAt(id)                → set manual payment date
delBill(id)                  → delete bill
nextDueDate(due,freq)        → calculates next recurring due date
isDueSoon(due)               → returns true if due within 7 days

── SCHEDULE ──

buildScheduleGrid(id,secs)   → renders one schedule grid (kitchen or serving)

getWeekDates()               → returns array of 7 date strings for current week
getMonday(d)                 → returns Monday of any given date
setWeekLabel()               → updates the "Mar 24 – Mar 30" label

── SCHEDULE GRID CONFIG ──
GRID_SECTION_ROWS{}          → fixed named rows per section (Kim, Lee, Gu, etc.)
SECTION_PRINT_ORDER[]        → [SUSHI, KITCHEN, TEPPAN] print order
gridRowMatch()               → fuzzy name match for grid rows
shiftSortKey()               → sort order: name-only first, half, then timed

openShiftModal()             → fallback modal shift add

_doAddShift()                → core shift write to Firebase
delShift(id)                 → remove a shift
confirmQuickShift()          → quick-shift modal submit

── QUICK-ADD STAFF PANEL ──
renderStaffQuickPanel()      → renders clickable staff chips above grid
selectQuickEmp(id,role)      → selects/deselects a staff chip

confirmReqOff()              → saves time-off request
renderReqOffs()              → renders reqoff tags for current week

── RESERVATIONS / FORECAST ──

openSheetModal()             → opens sheet modal + builds previews

copySheetData(which)         → copies kitchen or serving as TSV for Sheets
